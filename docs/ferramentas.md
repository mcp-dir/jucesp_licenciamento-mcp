# Ferramentas

JUCESP: Consulta Pública de Licenciamento expõe 1 ferramenta (todas somente leitura).

### 1. `jucesp_licenciamento_consultar`
**Input**: `cnpj`

Consulta pública de licenciamento de uma empresa na Junta Comercial de São Paulo (JUCESP) pelo CNPJ.

## Prompts de exemplo

```
Situação de licenciamento do CNPJ 00.000.000/0001-00 na JUCESP?
```
